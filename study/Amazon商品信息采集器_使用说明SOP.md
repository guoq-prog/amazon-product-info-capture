# Amazon 商品信息采集器｜扩展版使用说明

版本：v1.4.05

## 一、需要发送的文件

只需要发送：

- `amazon_review_capture_extension.zip`
- 本说明文件（可选）

不需要发送 `amazon_asin_browser.html`。扩展已经包含批量 ASIN 输入、站点选择、自动跳转、异常纠错和导出功能。

## 二、安装

1. 解压 `amazon_review_capture_extension.zip`。
2. 打开 Chrome 或 Edge 的扩展管理页：`chrome://extensions` 或 `edge://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的 `amazon_review_capture_extension` 文件夹。
6. 打开 Amazon 商品详情页并刷新，右下角出现采集面板即安装成功。

## 三、批量采集

1. 打开任意 Amazon 商品详情页。
2. 点击面板的“设置 / 更多”→“批量采集队列”。
3. 选择目标站点，粘贴多个 ASIN、Amazon 链接或混合文本。
4. 点击“开始 / 重置队列”。扩展会自动逐页采集并保存数据和图片 URL。
5. 可在后台运行，但电脑不能睡眠，浏览器和标签页不能关闭。

## 四、自动纠错

队列遇到验证码、404、商品不可用、页面超时、无星级商品或跳出 Amazon 页面时，会记录对应 ASIN 和错误原因，并继续处理后续项目。导出时可勾选“队列状态”和“错误原因”。

## 五、导出

- “导出最新”：按设置中勾选的字段导出 CSV / JSON。
- “导出历史”：导出历史快照。
- “导出全部图片 ZIP”：按 ASIN 分文件夹导出主图、副图和 A+ 图片。
- “导出全部图片清单 CSV”：每张图片一行，适合后续下载或整理。

五点描述在 CSV 中会自动拆分为 `bulletPoint1` 至 `bulletPoint5`。

## 六、常见问题

- 看不到面板：确认扩展已启用，打开的是 Amazon 商品详情页并刷新。
- 服务工作进程显示“不活动”：这是 Chrome 的正常休眠状态，有事件时会自动唤醒。
- 队列暂停：处理验证码或异常页面后，点击“重新读取 Alt+R”继续。
- 图片下载不完整：使用图片清单 CSV 中的高清 URL 手动下载。

采集记录仅保存在浏览器本地，不会上传到服务器。
