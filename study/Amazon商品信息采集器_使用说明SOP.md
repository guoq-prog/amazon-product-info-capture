# Amazon 商品信息采集器｜使用说明 SOP

版本：v1.3.30

## 一、文件说明

分发包中包含：

- `amazon_asin_browser.html`：ASIN 管理和商品链接工具
- `amazon_review_capture_extension.zip`：Chrome / Edge 采集扩展
- `Amazon商品信息采集器_使用说明SOP.md`：本说明

HTML 和 ZIP 请保持在同一个文件夹中。不要只发送 HTML，否则用户无法安装采集扩展。

## 二、首次安装

1. 解压分发包到本地文件夹。
2. 双击打开 `amazon_asin_browser.html`。
3. 点击页面上的“下载新版商品信息采集器”。
4. 解压 `amazon_review_capture_extension.zip`。
5. 打开 Chrome 或 Edge 的扩展管理页：
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
6. 开启右上角“开发者模式”。
7. 点击“加载已解压的扩展程序”。
8. 选择解压后的 `amazon_review_capture_extension` 文件夹。
9. 打开 Amazon 商品详情页并刷新，右下角出现“Amazon 商品信息采集器”即安装成功。

## 三、采集商品信息

1. 在 HTML 工具中粘贴 ASIN、Amazon 链接或混合文本。
2. 点击“读取 ASIN”。
3. 点击“打开第一个未访问”或列表中的 ASIN。
4. 扩展会在商品详情页自动采集信息。
5. 采集成功后，面板显示“√ 已成功读取”。

### 批量采集多个 ASIN

1. 先打开任意一个 Amazon 商品详情页并确认扩展面板正常显示。
2. 点击“设置 / 更多”，打开“批量采集队列”。
3. 一次粘贴多个 ASIN、Amazon 商品链接或混合文本，点击“开始 / 重置队列”。
4. 扩展会按当前站点自动逐页打开并采集；每个 ASIN 成功后会保存数据、主图/副图和 A+ 图片 URL，再进入下一个页面。
5. 中途可以点击“停止队列”。页面加载失败或遇到验证码时，队列会停在当前 ASIN，处理页面后点击“重新读取”即可继续。
6. 全部完成后，在“导出最新”导出按勾选字段生成的 CSV；在“导出与数据”中可导出所有已记录 ASIN 的图片 ZIP 和逐图图片清单 CSV。

扩展可读取的字段包括：标题、品牌、父 ASIN、星级、评分数量、类目、BSR、五点描述、商品描述、主图和副图 URL、A+ 图片 URL、图片数量等。实际字段取决于商品页面、站点和登录状态。

## 四、手动采集

在扩展“功能设置”中关闭“自动采集”后，可以使用：

- 页面按钮：`重新读取（Alt+R）`
- 键盘快捷键：`Alt+R`

## 五、导出数据

前台按钮可以直接：

- 导出最新记录
- 导出历史快照
- 清空最新记录
- 清空历史记录

在“设置 / 更多 → 功能设置”中，可以勾选需要导出的字段。CSV 导出时，五点描述会自动拆成 `bulletPoint1` 至 `bulletPoint5` 五列。

在“设置 / 更多 → 导出与数据”中可以：

- 导出全部已记录 ASIN 的图片 ZIP（每个 ASIN 单独文件夹）
- 导出全部图片清单 CSV

图片清单采用“一张图片一行”的结构，避免不同 ASIN 的图片数量不同造成列错位。

## 六、常见问题

### 看不到采集面板

- 确认扩展已在扩展管理页启用。
- 确认打开的是 Amazon 商品详情页，而不是搜索页或验证码页。
- 刷新商品页。
- 如果使用无痕窗口，在扩展详情中开启“允许无痕”。

### 某些字段为空

Amazon 不同站点、类目、变体和登录状态的页面结构不同。验证码、登录提示、Cookie 页面和部分动态内容可能无法读取。

### 图片 ZIP 下载不完整

Amazon 图片服务器可能限制浏览器跨域读取。此时可使用“图片清单 CSV”中的 URL 手动下载。

### 如何检查更新

HTML 工具和扩展都可以从 GitHub 检查更新。更新后下载新的 ZIP，在扩展管理页点击“重新加载”，或重新加载解压后的扩展文件夹。

## 七、数据和隐私

采集记录保存在浏览器本地扩展存储中，不会自动上传到服务器。导出的 CSV、JSON 和图片 ZIP 请自行妥善保管。
