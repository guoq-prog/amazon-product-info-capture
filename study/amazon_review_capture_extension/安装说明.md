# Amazon 商品信息采集器（Chrome / Edge 扩展版）

这是独立的 Chrome / Edge Amazon 商品信息采集扩展，不需要 HTML 工具即可使用。扩展直接在 Amazon 商品详情页加载采集面板，并把记录保存在浏览器扩展的本地存储中；不会上传数据。当前版本 v1.4.07。

## 安装

1. 停用旧的 Tampermonkey 评分脚本，避免出现两个面板。
2. 在 Chrome 或 Edge 打开扩展管理页：`chrome://extensions` 或 `edge://extensions`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本文件所在的文件夹：`study/amazon_review_capture_extension`。
6. 打开任一 Amazon 商品详情页并刷新；右下角应出现“Amazon 商品信息采集器”。
7. 关闭自动采集后，可按 `Alt+R` 手动采集当前页面。
8. 已安装旧版本时，在扩展管理页点击本扩展的“重新加载”，再刷新商品页。

## 使用与限制

- 打开 `/dp/ASIN` 商品详情页时会自动采集；也可点“重新读取”。
- 打开批量采集队列，粘贴多个 ASIN 后点击“开始 / 重置队列”；每个页面读取成功后会自动跳转下一个 ASIN。完成后在“导出与数据”中导出全部图片 ZIP 或清单 CSV。
- “评分数量”是 Amazon 页面显示的总 rating count，可能包含未写文字评论的星级评分。
- 图片链接优先从页面的动态图片数据中选择最大规格；若页面未公开真正原图，无法保证取得源文件。
- 验证码、登录提示、Cookie 同意页或非商品详情页无法读取数据。
- 若使用无痕窗口，需要在扩展详情页开启“允许无痕”。
- 在“设置 / 更多 → 打赏 / 支持作者”中点击“发送反馈邮件”，会自动打开默认邮件客户端并填写收件人、版本、ASIN 和问题模板。
