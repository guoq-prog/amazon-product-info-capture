# Amazon 商品信息采集器

Chrome / Edge 本地扩展，用于采集 Amazon 商品信息、评分、图片和 Listing 内容。

## 安装

1. 打开 `chrome://extensions` 或 `edge://extensions`。
2. 开启“开发者模式”。
3. 解压发布版 ZIP，点击“加载已解压的扩展程序”。
4. 选择 `amazon_review_capture_extension` 文件夹。

## 发布

发布版位于 `amazon_review_capture_extension.zip`。版本信息位于 `version.json`，HTML 和扩展可从 GitHub Raw 地址检查更新。

代码可以压缩或混淆以提高抄袭成本，但浏览器扩展无法做到真正隐藏源代码。
